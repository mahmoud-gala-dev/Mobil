# 🎨 دليل إنشاء أيقونة التطبيق - خطوات سريعة

## 📱 المطلوب

يجب إنشاء ملفين:
1. `app_icon.png` - الأيقونة الكاملة (1024x1024)
2. `app_icon_foreground.png` - الأيقونة الشفافة للـ Adaptive Icon (1024x1024)

---

## 🚀 الطريقة الأسرع (موصى بها)

### استخدام أداة أونلاين مجانية

#### الخيار 1: App Icon Generator (الأسهل)
1. اذهب إلى: https://www.appicon.co/
2. ارفع شعار أو صورة للمتجر
3. اختر:
   - iOS: Yes
   - Android: Yes
4. اضغط "Generate"
5. حمّل الملف الناتج
6. استخرج الملفات وانسخ:
   - أي صورة بحجم 1024x1024 → `app_icon.png`
   - نفس الصورة بخلفية شفافة → `app_icon_foreground.png`

#### الخيار 2: Icon Kitchen (لـ Android)
1. اذهب إلى: https://icon.kitchen/
2. اختر "Image" وارفع صورة
3. عدّل الألوان والحجم
4. حمّل النتيجة

## 🎨 إنشاء أيقونة بسيطة باستخدام Canva

### الخطوات:

1. **افتح Canva:**
   - اذهب إلى: https://www.canva.com
   - اختر "Create a design"
   - حجم مخصص: 1024 x 1024 بكسل

2. **التصميم:**
   - خلفية: لون أخضر `#16A34A` (أو تدرج)
   - أيقونة: ابحث عن "shopping bag" أو "store" في العناصر
   - نص: اختياري (حرف E أو اسم المتجر)

3. **التصدير:**
   - اضغط "Share" → "Download"
   - النوع: PNG
   - الجودة: أعلى جودة
   - احفظ باسم: `app_icon.png`

4. **للنسخة الشفافة:**
   - أزل الخلفية (استخدم أداة Background Remover في Canva Pro)
   - أو:
     - اذهب إلى https://www.remove.bg/
     - ارفع الصورة
     - حمّل النتيجة بدون خلفية
   - احفظ باسم: `app_icon_foreground.png`

إذا كنت تريد تشغيل التطبيق الآن بدون تصميم أيقونة:

### حل مؤقت سريع:

1. **ابحث في Google Images عن:**
   ```
   "shopping bag icon green 1024x1024"
   "store icon 1024"
   "e-commerce icon"
   ```

2. **حمّل أي صورة مناسبة**

3. **استخدم موقع لتغيير الحجم:**
   - https://www.iloveimg.com/resize-image
   - غيّر الحجم إلى 1024x1024
   - احفظ باسم `app_icon.png`

4. **للنسخة الشفافة:**
   - نفس الصورة على https://www.remove.bg/
   - احفظ باسم `app_icon_foreground.png`
