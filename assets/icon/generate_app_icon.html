🛍️ Engeb - أيقونة التطبيق

أيقونة احترافية لمتجرك الإلكتروني

📋 طريقة الاستخدام:

  1. اضغط على زر "تحميل جميع الأحجام" لتحميل الأيقونات
  2. احفظ الملفات في مجلد assets/icon/
  3. قم بتشغيل الأمر: flutter pub run flutter_launcher_icons
  4. أو استخدم: flutter pub get ثم dart run flutter_launcher_icons
